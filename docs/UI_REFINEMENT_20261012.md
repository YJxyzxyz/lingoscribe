# 2026-10-12 界面与美术优化

延续森林绿、纸白和原创聆写标志。审查对象是 USB 连接的 vivo V2073A 上独立 QA 应用，截图均为本轮实际采集，不是设计稿或预置产品记录。识别示例来自已有真实原生测试的公开音频。

## 流程与发现

1. **资料库**：基础功能可用；标题、搜索和记录卡片占据较多高度，首屏记录较少。已缩短中文标题、调整留白和卡片密度，状态显示为清晰标签，加入真实清除搜索操作。
2. **离线模型**：下载、选择、删除可用；默认排序使当前 Qwen 模型不在首屏，完整性技术说明占据优先位置。已将当前模型置顶并用颜色和勾选状态标识，说明移至列表后，文案说明校验的用户价值。
3. **设置与转写选项**：基础偏好可用；默认设置不改变已导入音频，用户可能误以为改变默认语言后旧记录也会使用新语言。增加单份音频的语言与术语选项，明确与默认偏好的区别，并真正写入该记录；混合语音继续建议自动识别。
4. **回听与校对**：原文保留、标记、回放可用；较大标题和分散操作减少正文空间，搜索只有筛选而没有词语定位。已压缩标题区、统一段落动作布局，增加保留完整原文的字面搜索高亮、清除搜索及标记筛选状态。

## 美术与验证

- 使用统一森林绿主色、淡绿选中背景、纸白页面、20 px 卡片圆角和 14 px 输入/按钮圆角；系统字体及既有品牌标志保留。
- 使用 ImageGen 生成原创透明麦克风、纸张与叶片插画，放入真正的空资料库；不作为录音波形或转写数据。源文件 `apps/mobile/assets/art/private-audio-library.png`，RGBA 1536×1024，透明通道已检查；显示尺寸 190×126 dp，并按显示需求限制解码宽度。无文字或第三方标志。
- 53 项应用测试及静态检查通过，包含 320 px / 大字体 / 英文 / 键盘布局、字面 C++ 搜索高亮不破坏原文、真实 SQLite 搜索清除以及单份音频偏好持久化且不修改默认值。
- 新界面真机复查与最新 Qwen 原生流程验证将在安装后补充；桌面空状态是实际 Flutter 渲染，不代表手机验收。
