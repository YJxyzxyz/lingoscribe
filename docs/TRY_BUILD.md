# 开发版试用

当前版本 0.1.0 是功能验证用开发版，尚未完成商业发布验收。源码版本、产物摘要及验证范围以交付目录的 `manifest.json` 和 [状态记录](STATUS.md) 为准。

## Android

优先试用 `lingoscribe-0.1.0-dev-arm64-release.apk`：约 24.5 MB，适用于 Android 8 或以上的 ARM64 手机，采用发布编译配置和开发证书签名。签名校验和 16 KB 静态对齐检查已通过；它仍是开发测试包，不是商店正式版，手机运行尚待验收。
另提供较大的 `lingoscribe-0.1.0-dev-android.apk`，采用 Debug 配置并包含 ARM64 / x86_64 两种架构，供调试与模拟器使用。
首次安装时只为打开 APK 的应用临时允许“安装未知应用”；安装完成后可关闭该授权。

1. 打开聆写，进入“离线模型”。首次下载需要网络，也可以导入已下载的官方模型文件。
2. 小体积 Base 约 60 MB；较大的 Small 约 190 MB。下载体积不代表运行内存。中文与双语录音可优先试 Small，实际效果和速度需要在自己的设备上核对。
3. 下载完成后关闭网络，录制短音频或从系统文件选择器导入。点击录音时才请求麦克风权限。
4. 选择自动语言以保留中英混合原声；术语提示可以填写人名和专业词，结果仍需校对。
5. 转写时保持应用在前台。完成后点击时间戳回听，编辑文本、添加标记，再导出 TXT、Markdown、SRT、VTT 或 JSON。

当前模型在自然中英混合对话中仍有明显误识别，准确率尚未达到商业验收。替代引擎研究尚未成为 App 功能；重要文字需要回听校对。

录音切到后台会自动暂停，返回后需要手动继续。首版不承诺锁屏持续录音或后台持续转写。无语音音频可以产生空文本，这不是预置成功结果。

重要音频请保留外部副本。应用没有云同步，卸载会删除沙箱内资料；本次两个 APK 具有相同开发证书和应用 ID，可用于同一开发安装的切换，但不保证将来与正式签名兼容，升级前先导出需要保留的音频与文字。不要通过卸载来处理模型下载问题，先尝试取消、重新下载或文件导入。

默认模型源是 Hugging Face，可在模型页启用已披露的备用站。下载站会收到 IP 和模型请求；应用不上传录音或转写。导出的内容交给其他应用后，由接收应用处理。

## iOS 与商店包

`lingoscribe-0.1.0-unsigned-ios.zip` 包含 macOS CI 编译的未签名 App 及检查报告，不能直接安装到普通 iPhone，也不是可上传的 IPA。
`lingoscribe-0.1.0-unsigned-android.aab` 是未签名发布配置产物，不能作为 APK 安装或直接提交商店。
正式 iPhone 安装、TestFlight 和商店发布需开发者账号、签名及发行信息；当前用户尚未提供这些条件。

## 核对交付

在 Windows PowerShell 使用 `Get-FileHash <文件路径> -Algorithm SHA256`，与 `manifest.json` 中对应文件的 `sha256` 比较。摘要一致只证明文件字节一致，不代表已经通过手机性能或商店审核。
问题记录应包括系统版本、手机型号、模型、操作步骤及错误提示；分享录音前先确认内容可以提供。
