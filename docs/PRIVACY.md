# 聆写 / LingoScribe 隐私说明

生效日期：2026-10-09。本文对应当前实现；发布前需填写实际运营主体及公开联系方式并重新核对构建。

## 你的录音和文字

LingoScribe 在设备本地录音、解码、转写、编辑及搜索。应用没有将录音、导入文件、文字或术语提示上传到服务器的功能。
无需注册账号，应用不包含广告、用户行为统计或第三方崩溃上报 SDK。
音频、文本和模型保存在应用私有目录；Android 关闭应用自动备份，iOS 私有数据目录标记为不参与备份。
系统迁移、设备管理或厂商工具的行为仍需根据目标设备验证。当前没有额外的应用级加密，安全保护依赖操作系统沙箱及设备锁屏。

## 模型下载

只有用户主动下载模型时，应用才会连接 Hugging Face。用户可手动选择备用站 hf-mirror.com，也可以完全通过文件导入模型。
下载请求包含 IP 地址、请求时间和模型文件路径，提供站点可能依据自己的隐私规则记录请求。
不会在模型请求中附带用户录音、转写、术语、账号标识或设备广告标识。
下载文件需要通过固定大小和 SHA-256 验证后才能安装，删除模型不会删除你的转写。

## 麦克风权限

仅在你点击录音时请求麦克风权限。拒绝权限后仍可以导入文件并进行离线转写。
系统文件选择器仅用于用户主动选中的文件，不请求整个媒体库或通讯录权限。
首次录音、来电中断和后台暂停需要在支持的操作系统上验收。

## 导出、分享和删除

导出会在应用临时目录生成 TXT、Markdown、SRT、VTT 或 JSON 文件，并通过系统分享界面交给你选择的目标。
目标应用会按照自己的隐私规则处理文件；请只分享给信任的应用或接收者。
临时导出文件由系统缓存机制清理，也可以在“设置 → 清除临时导出缓存”主动清理，保留录音和资料库。
你可以逐条删除本地记录及音频。已经分享给其他应用的副本不会随之删除。
卸载应用会删除应用本地资料；重要内容请主动导出保存。

## 购买和联系

拟采用商店付费下载，支付与购买记录由 Apple 或相应 Android 商店处理；应用不收集银行卡或自行处理支付。
正式发布前，运营方应在公开支持页面提供真实名称、可用邮箱及问题反馈方式。
转写可能存在错误，重要内容应回听确认。请遵守录音所在地的授权规则，并征得参与者同意。
