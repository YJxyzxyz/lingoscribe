# 商业验收门槛

产品需要可复核的质量门槛。以下为本项目自主设定的发布条件，不代表行业统一标准。通过构建、单个样例或研究对照不能替代这些条件。

## 准确率

独立于调参样本的授权音频：至少十位说话人，中文、英文、混合各至少一百条；覆盖短笔记、连续对话、低音量和环境噪声。保留人工参考、选择规则、文件/模型/引擎摘要、规范化规则和全部失败条目。
清晰自然语音目标：中文 CER ≤ 10%，英文 WER ≤ 15%，混合中文 CER ≤ 15%、英文 WER ≤ 25%。简繁体与缩写规范化可另外报告，必须同时保留原始指标，不能只展示较好结果。
无语音、低信噪比和损坏音频单独验收：不以胡编文字作为成功结果，明确显示空结果或失败。专业名词提示和普通输入分别计分。

当前证据：Qwen Dart 路径仅两位说话人、90 条；中文 9.5%、英文 22.9%、混合中文 17.5% / 英文 31.9%，覆盖与多项指标尚未达到上述要求。结果应继续指导改进，不能作为商业验收通过证明。
另在固定 ASCEND validation split、三位额外说话人的 90 条上得到中文 3.8%、英文 20.4%、混合中文 26.6% / 英文 44.3%，见 `validation/qwen-dart-holdout-evaluation.json`。此子集在推理前按相同规则选定，与此前调参使用的 test split 说话人不同；不能证明与模型预训练数据完全独立。两次合计仅五位说话人，混合语音仍明显不达标，未通过准确率验收。

94150a8 的完整回归在同一 180 条、五位说话人上得到纯中文 CER 5.6%、纯英文 WER 18.7%、混合中文 CER 17.2% / 英文 WER 35.7%，见 `validation/qwen-context-exact-comparison.json`。读入上下文和尾部样本后有整体改善，但一个原始混合英文子集略退步；仍不满足英文、混合及人数/数量要求。此集已用于诊断，不再称为新的独立验收集。

## 设备与稳定性

2026-10-12 新增固定 300 条、十位新说话人的实际 Dart 工作线程与 GGML VAD 评测。选样规则、模型和策略在推理前冻结，全部说话人及音频摘要与先前 180 条不同；每种语言 100 条。中文 CER 5.0%、英文 WER 17.1%、混合中文 CER 11.6% / 英文 WER 33.3%。该样本达到人数/数量门槛及中文错误率目标，英文和混合英文仍未达到。主要覆盖短自然对话，不代替低音量、噪声及长对话；无法证明未出现在模型预训练数据中。详见 `validation/ascend-unseen-speakers-protocol.json` 与 `validation/qwen-unseen-speakers-evaluation.json`。Windows 参考运行库只用于研究，不随手机分发；不是手机性能证据。数据集与旧回归不同，不作直接前后提升比较。

至少两代支持所选模型的 iPhone，以及低/中/高内存 Android；高内存模型明确限制适用设备，轻量模型另外验收。
在记录的设备与系统上测量首次载入、整体转写 RTF、峰值内存、耗电和热状态。目标为主要支持设备的中位 RTF ≤ 1、95 分位 ≤ 2；高内存模型峰值进程内存目标 ≤ 2 GB，且不触发系统内存终止。未实测的设备不写速度和电量承诺。
连续录音两小时、长对话、暂停/继续、来电/耳机/后台/锁屏、低存储、进程退出和重启恢复均须实际测试。重要流程重复运行无崩溃、无死锁、无丢失原始音频；取消保留原音频和已保存校对。
持久化、更新迁移、全文搜索、时间戳回听、字幕兼容、删除与导出在实际手机完成，不能由隔离平台通道的单元测试替代。

## 产品与发布

首次使用、权限拒绝、模型安装/损坏/取消、飞行模式、英文与中文、大字体、屏幕阅读器以及明确错误恢复流程完成真机验收。
抓包与源码复核只允许主动模型请求和用户主动分享；无音频/文字上传、统计和广告行为。核对最终构建的依赖许可、原生实现、备份及隐私声明。
完成真实经营/联系信息、公开支持及隐私页面、名称核查、两端签名归档与商店测试。所有验收证据对应到实际源码、产物摘要和构建编号后，才创建正式发布标签并提交商店。

## 当前结论

最新 97a420f 上下文策略已在同一 vivo 真机完成真实 Qwen 集成断言：11 秒英文夹具流程 38.416 秒（Debug RTF 3.49），全流程采样最大 PSS 1,466,939 KiB（约 1.40 GiB）。见 `validation/android-physical-qwen-97a420f.json`。OEM 安装成功后自动启动影响了最初测试启动，超时记录未算通过；核对已安装 APK 摘要后重新完整运行，断言全部通过。该单样例速度仍不达标，不能从一次 Debug 结果推断正式版优化收益、总体准确率或功耗。

尚未达到商业发布验收。vivo V2073A / Android 13 的独立 QA 安装已通过真实短录音、六种解码、Base 与 Qwen 转写、SQLite 校对/标记及 Qwen 准备阶段取消保留音频。8a3075a Debug 基线中，11 秒英文 Base 流程约 12.894 秒、Qwen 流程约 41.490 秒（RTF 3.77），Qwen 全流程采样最大 PSS 1,392,108 KiB（约 1.33 GiB）；尚不能满足速度目标。报告见 `validation/android-physical-{base,qwen}-8a3075a.json`。这些是单个英文夹具及稀疏内存采样，不代表最新上下文策略的物理性能、整体准确率、长录音、中断、精确峰值或耗电。5ec087c 双平台 CI 及 iOS 26.2 编译产物检查通过，仍缺签名及物理 iPhone 验收。开发者账号、发行资料、更多 Android 机型及 iPhone 仍待补齐。
