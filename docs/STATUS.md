# 交付状态（持续更新）

目标是可商业发布的应用。源码实现、自动化验证、真机验证和商店上线分别记录，不能互相代替。

- 已完成源码：竞品研究与产品决策；Flutter 双平台工程；真实原生推理和音频归一化；录音、资料库、回听校对、标记、搜索、五种导出格式及可验证模型管理；原创品牌资源与隐私/上架文档。

- 正在执行：Android 安装包编译、专用 Android 模拟器的原生集成；macOS iOS CI 编译；进一步的错误恢复与体验完善。
- 尚未验证：两端手机准确率/性能/功耗、长音频、来电/后台/低存储行为、iOS 签名归档、商店审核。

## 已知局限

- 当前界面为中文，国际发行需要英文 UI 本地化。
- 首版转写要求保持应用在前台；不宣传后台持续转写或实时转写。
- 首次模型网络可用性因地区不同，已提供备用下载站和文件导入；两端手机的模型下载需验证。
- SDK 与依赖版本固定；部分第三方 Android 插件仍使用兼容 Kotlin 配置，需要在后续升级中迁移。
- 当前录音和音频导入路径已实现，原生手机验收仍在执行；不以 UI 测试的麦克风隔离通道代替真机结果。

## 需要外部条件的项目

- iOS 构建必须有 macOS + Xcode 或可用的 macOS CI，正式签名需 Apple Developer 团队及凭据。
- Google Play / App Store 发布需开发者账号、经营主体/联系信息、商店内测与签名材料。
- 精准效果与耗电需要实际手机及合法双语测试音频。不会用模拟数据声称已通过这些测试。

详细验证结果和版本提交在工作推进后补充。
